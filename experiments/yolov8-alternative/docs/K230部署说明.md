# 庐山派 K230：YOLOv8 小铁球检测部署说明

主程序：`k230_yolov8_steel_ball.py`

## 1. 运行前提

- 开发板：立创·庐山派 K230（标准版）。
- 系统：与板型匹配的 CanMV MicroPython 固件；本程序按 CanMV K230 v1.8 的官方 YOLO 模块接口编写。
- 显示：默认使用 3.1 寸 ST7701 LCD，`display_mode="lcd"`，分辨率 800×480。
- 模型：自训练的单类别 YOLOv8 检测模型，类别名称为 `steel_ball`，并已转换成 K230 的 `.kmodel`。

普通 COCO 权重没有“小铁球”这个专门类别；即使其中的 `sports ball` 偶尔能识别，也不适合比赛。必须用真实赛场光照、背景、距离和相机角度采集并标注小铁球数据。

## 2. 模型训练与转换

数据集 YAML 示例：

```yaml
path: D:/datasets/steel_ball
train: images/train
val: images/val
names:
  0: steel_ball
```

建议先用 YOLOv8n 和 640 输入训练：

```bash
yolo detect train data=steel_ball.yaml model=yolov8n.pt epochs=200 imgsz=640 batch=16
yolo export model=runs/detect/train/weights/best.pt format=onnx imgsz=640
```

按照嘉楠官方 `test_yolov8/detect/to_kmodel.py` 工具转换：

```bash
python to_kmodel.py --target k230 \
  --model ../../runs/detect/train/weights/best.onnx \
  --dataset ../calibration_images \
  --input_width 640 --input_height 640 --ptq_option 0
```

量化校准图片要尽量来自最终摄像头与真实比赛环境，否则反光金属球量化后容易漏检。

## 3. 上传并运行

1. 把转换后的模型重命名并上传为：
   `/sdcard/steel_ball_yolov8n_640.kmodel`
2. 把 `k230_yolov8_steel_ball.py` 上传到开发板，或直接在 CanMV IDE / CanMV IDE Web 中打开运行。
3. 需要上电自动运行时，将代码保存为 `/sdcard/main.py`。
4. LCD 会显示检测框；USB 虚拟串口会周期性输出：

```text
BALL,中心X,中心Y,宽度,高度,置信度
NO_BALL
```

坐标基于代码中的 `RGB888P_SIZE = [640, 360]`，可直接用于后续舵机、云台或运动控制。

## 4. 常用调参

- 漏检：把 `CONFIDENCE_THRESHOLD` 从 `0.30` 降到 `0.20~0.25`。
- 误检：升到 `0.40~0.55`，并增加硬负样本重新训练。
- 小球太远：保持 640 模型，缩小相机视场或增加训练中的远距离小目标样本。
- 速度不足：重新训练并转换 320×320 模型；代码中的 `MODEL_INPUT_SIZE` 和模型文件必须一起改。
- 画面方向错误：在 `PipeLine` 或 Sensor 初始化处按摄像头安装方向设置镜像/翻转。
- `RuntimeError: init panel failed`：`"lcd"` 特指 ST7701 屏；使用 HDMI 扩展板改为 `"hdmi"`，只在 IDE/虚拟显示可尝试 `"virt"`。

## 5. 重要兼容性提示

`MODEL_INPUT_SIZE` 必须与训练、ONNX 导出、KModel 转换时使用的尺寸完全一致，`LABELS` 数量必须等于模型类别数。固件中的 `/sdcard/libs/YOLO.py`、`PipeLine.py` 也应与当前固件配套，不要混用旧版示例库或手动加入旧版 `MediaManager` 初始化代码。
